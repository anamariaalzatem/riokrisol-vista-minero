# Vista del minero (boceto)

Boceto de la página de seguimiento para el titular de un proyecto minero: planta con sus frentes de trabajo, ruta de formalización, producción, presupuesto y tareas urgentes.

Todos los datos son de ejemplo e inventados. No corresponde a ningún proyecto real.

Es un único archivo, `index.html`, sin dependencias salvo las tipografías de Google Fonts.
